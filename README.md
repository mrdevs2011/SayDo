# SayDo

Say it — done. Voice-triggered screen shortcuts for Android.

Record a tap, long-press, or swipe with the floating **START** button, set a trigger phrase, then say it anytime (even on the lock screen).

## Features
- Floating Start/Stop bubble
- Gesture recording with visual feedback
- Voice triggers (English)
- Works over other apps and when the screen is locked
- Lock-screen shortcuts: recorded on the lock screen (swipe + PIN taps), replayed from the lock screen
- Offline gate: no internet = SayDo is fully off
- Pure native Android (no WebView)

## Install
Sideload the APK from [Releases](https://github.com/mrdevs2011/SayDo/releases). Enable **Accessibility** and **Display over other apps** for SayDo.

## Package
`uz.saydo.app`
